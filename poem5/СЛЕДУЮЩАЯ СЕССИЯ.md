## 20.10 — его слово «слишком сложно» + «крестик не закрывает уровень»

- Крестик: `confirm()` во встроенных браузерах (MAX, Telegram) заблокирован и молча отвечает «нет».
  Теперь свой диалог `yesNo()` («Выйти» / «Остаться»). То же для «Начать всё заново».
- Проще: 5 уровней (Читай и слушай → Строчки 1–4 → Строчки 5–8 → Пропуски → Весь стих), плитки без
  лишней, в пропусках 3 варианта. Экран стиха: без «Медленно» («Повторяй за мной» сам медленный),
  3 ступени (все / половина / первые буквы), 3 совета. Вид экрана не сохраняется — каждый вход с переводом.
